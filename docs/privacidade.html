Política de Privacidade

Boletos Protest · Última atualização: 1º de outubro de 2026

O Boletos Protest é uma ferramenta pessoal, não pública, de uso exclusivo de Dalgiza Borges e Rafael Borges, executada apenas em computador pessoal. Esta política explica como o programa trata os dados da conta Google que ele acessa.

Neste texto, “usuária” é a pessoa que autoriza o aplicativo em sua própria conta Google: Dalgiza Borges ou Rafael Borges, os únicos usuários.

Dados acessados

Com autorização da usuária, o programa acessa a conta Gmail dela para:

  • ler e-mails de cobrança de condomínio enviados pela administradora;
  • baixar os boletos em PDF indicados nesses e-mails;
  • criar um rascunho de e-mail com os boletos anexados.

Como os dados são usados

Os dados são usados exclusivamente para a finalidade descrita acima, de forma visível à usuária. O programa não envia e-mails sozinho: o rascunho fica na conta dela até que ela decida enviá-lo.

Armazenamento

Os boletos baixados e o token de autorização do Google ficam somente no computador da usuária. Não existe servidor do desenvolvedor, banco de dados externo ou serviço de terceiros que receba, copie ou guarde esses dados.

Compartilhamento

Os dados não são vendidos, divulgados nem compartilhados com terceiros. Não são usados para publicidade nem para treinar modelos de inteligência artificial. O único destinatário dos documentos é aquele que a usuária escolher ao enviar o rascunho.

Uso de dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação de acesso

A usuária pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Também pode apagar o token salvo e os boletos baixados diretamente no computador.
